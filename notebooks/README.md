# Notebooks

Copier un template pour chaque membre et remplacer `<prenom>` par son prénom :

- `01_eda_<prenom>.ipynb` : exploration ;
- `02_preprocessing_<prenom>.ipynb` : préparation ;
- `03_modeling_<prenom>.ipynb` : modélisation.

Les notebooks doivent être exécutés depuis la racine du dépôt et utiliser les
fonctions de `src/`. Ne pas y enregistrer de données brutes ni de secrets.
